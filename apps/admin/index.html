Allowed Domains

The embed only loads on these domains. This prevents unauthorised use of your client key.

Single Sign-On ○ Off

Sign players in with the account they already have on your site — no separate registration, no repeated logins. Your page passes each logged-in user's id, email and name together with a signature computed from the secret below; we verify the signature server-side before signing anyone in.

Your SSO secret

Keep the secret in server-rendered template code only — never in anything a visitor can view-source. Anyone holding it can sign your players in.

Shopify snippet

Shopify's Liquid computes the signature natively (hmac_sha256) — no app needed, this replaces your embed snippet as-is:

On any other platform, render the same four data-sso-* attributes server-side, from your logged-in user, on the seamless script embed. The signature is the hex HMAC-SHA256 of id + ":" + email using your secret, computed on your server — never in code a visitor can view.

SSO needs the seamless script embed (above), not the classic iframe, and requires at least one entry under Allowed Domains — sign-in is only accepted from those domains, which is what stops a copied signature being replayed from another site.

Open the live widget →

How it's calculated
Started players — counted from real lineups you enter in Data Manager for Premier League 2026/27 fixtures. Fewer distinct players used means a more settled starting XI.
Everything else (participation, lineup count, nationalities, age, zodiac) needs data Data Manager doesn't collect yet — those tabs show every covered team at 0 rather than guessing.
Teams with no lineups entered yet still appear in the list at 0, so the widget never looks broken or empty while data is still coming in.

Open the live widget →

How it's calculated
Goal type — reconstructed from every goal you enter in Data Manager, in chronological order, comparing the score right before each goal to classify it as a Leading goal (took the lead), Equalising goal (levelled it), Reducing difference (behind, narrowed the gap), or Increasing difference (already ahead, extended it).
Minute range — filters by the exact minute you recorded for each goal, including stoppage time if you've entered goals past the 90th minute.
Opponent position needs league table data Data Manager doesn't track yet — that level shows 0 for now rather than guessing.
